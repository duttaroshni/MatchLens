# MatchLens ⚽

MatchLens is a football analytics platform built using Python to analyze player and team performance through data visualization and machine learning.

## Goals

- Analyze football datasets
- Compare player performance
- Discover player similarities using clustering
- Build an interactive dashboard using Streamlit

## Tech Stack

- Python
- Pandas
- NumPy
- Matplotlib
- Plotly
- Scikit-learn
- Streamlit
